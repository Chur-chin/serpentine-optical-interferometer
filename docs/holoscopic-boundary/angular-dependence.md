# Angular Dependence Study

We performed systematic rotation scans for both **Input** and **Output** positions.

## Output Position (Bottom → Top rotation)

- Strongest linear fringes observed around **+45°**
- Clear angular dependence with maximum contrast at specific orientations.

## Input Position (Top → Bottom rotation)

- Strongest linear fringes observed around **-10°**
- Optimal angles appear opposite to output position due to mounting orientation.

## Summary of Best Angles

| Position | Best Angle | Fringe Intensity | Note |
|----------|------------|------------------|------|
| Output | +45° | Very Strong | Maximum lines |
| Input | -10° | Very Strong | Maximum lines |
| Output | 0° | Medium | Dynamic internal pattern |
