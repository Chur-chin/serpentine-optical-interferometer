## 물리 요약 (노트 기준)

- 소각에서 광정차는 \(\theta\)의 **짝수 거듭제곱** 항이 지배적이며, 설계에 따라 한 팔에 \(\theta\)의 **선형** 항만 남길 수 있습니다.
- **위상민감 검출**로 DC·2차 성분을 걸러내면 남는 항으로 **각도·변위** 등을 읽을 수 있습니다.
