# Laser Diffraction Pattern Analysis: Z-axis Rotation Effect

## Overview

This thread documents how the **rotation angle along the z-axis** affects laser diffraction patterns — specifically the transition between:

- **Fringe line** (z-axis upper region): elongated streak above the central spot
- **Satellite spots** (z-axis lower region): discrete secondary maxima in a 2D grid below the beam

XY-plane orientation (square vs. rhombus) has **no significant effect** on which phenomenon dominates; only z-axis rotation matters.

## Key Findings

1. **Z-axis rotation drives a fringe-to-satellite transition** — the two regimes do not coexist at the same angle.
2. **Fringe line morphology** — vertically elongated streak above the central spot.
3. **Satellite spot morphology** — discrete 2D lattice below the central beam.
4. **XY-plane orientation is irrelevant** — only z-axis component governs fringe vs. satellite character.
5. **High reproducibility** across repeated trials.

---

## Physical Interpretation

- **Fringe line:** edge-oriented diffraction spreading along +z.
- **Satellite spots:** 2D periodicity producing separated diffraction orders along −z.
- **XY independence:** azimuthal reorientation without changing accessible z-axis orders.
