# Laser Diffraction Pattern Analysis: Z-axis Rotation Effect

Experimental recordings of how **rotation along the z-axis** affects the transition between:

- **Fringe line** (+z): elongated streak above the central spot (edge/aperture diffraction)
- **Satellite spots** (−z): discrete secondary maxima in a 2D grid below the beam

**Dates:** 2026-05-15 (photos + 8 clips), 2026-05-16 (extended z-rotation trials)  
**Detail:** [analysis.md](analysis.md)
