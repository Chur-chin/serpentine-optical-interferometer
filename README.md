# Serpentine optical interferometer

**세르펜틴(링) 광학 간섭계** — 사바르(Savart)형 분할·경로를 바탕으로, **출사 빔이 한 점으로 되돌아오는** 세르펜틴 레이아웃을 설계·조립한 기록입니다. 실험 노트 스케치, 파라메트릭 CAD, 광학대 실사가 함께 있습니다.

## 물리 요약 (노트 기준)

- 소각에서 광정차는 \(\theta\)의 **짝수 거듭제곱** 항으로 정리되는 부분이 크고, 설계에 따라 한쪽 팔에 \(\theta\)의 **선형** 항만 남기는 식으로 쓸 수 있습니다.
- **위상민감 검출**로 DC·2차 성분을 걸러내면, 남는 항으로 **각도·변위** 등을 읽는 구성이 가능합니다.
